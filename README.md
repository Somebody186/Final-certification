# Movie Library (Личная кинотека)
**Автор:** [Тимофей Григоренко]
**Язык:** Python 3.x + Tkinter

## Описание проекта

Графическое приложение для ведения личной коллекции фильмов. Позволяет добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга. Данные сохраняются в файл `movies.json`. Доступна фильтрация по жанру и году выпуска.

## Технологии

-   **Python:** основной язык.
-   **Tkinter:** для создания графического интерфейса.
-   **JSON:** для сохранения и загрузки данных.
-   **Git:** для контроля версий.

## Инструкция по запуску

1.  Установите Python (версии 3.6 и выше).
2.  Скачайте или клонируйте этот репозиторий.
3.  Запустите файл `main.py`:
    ```bash
    python main.py
    ```
4.  В появившемся окне введите данные о фильме и нажмите «Добавить фильм».
5.  Для фильтрации введите жанр или год в соответствующие поля и нажмите «Применить фильтры».
6.  Данные сохраняются автоматически при добавлении фильма.
