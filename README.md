# Random Task Generator

**Автор:** Somebody186

## Описание

Графическое приложение для генерации случайных задач и ведения их истории.  
Позволяет добавлять собственные задачи, генерировать случайные из предопределённого списка, фильтровать по типу, сохранять историю в JSON.

### Функциональность
- Добавление своей задачи с указанием типа (работа, личное, здоровье, учёба)
- Генерация случайной задачи из встроенного списка
- Фильтрация истории по типу задачи
- Удаление задач из истории
- Автоматическое сохранение в `tasks.json`
- Загрузка истории при запуске

## Требования
- Python 3.7+
- Стандартные библиотеки: tkinter, json, datetime, random, unittest

## Установка и запуск

```bash
git clone https://github.com/Somebody186/Final-certification.git
cd Final-certification
python main.py
```

Запуск тестов

```bash
python test_manager.py
```

Примеры использования

Добавление своей задачи

1. В поле "Описание задачи" введите: Купить молоко
2. Выберите тип: личное
3. Нажмите "Добавить задачу"

Генерация случайной задачи

· Нажмите кнопку "🎲 Сгенерировать случайную задачу" – задача добавится в таблицу автоматически.

Фильтрация истории

· Выберите тип (например, работа) в выпадающем списке фильтра
· Нажмите "Применить фильтр"
· Для сброса нажмите "Сбросить фильтр"

Удаление задачи

· Выделите строку в таблице
· Нажмите "Удалить выбранную задачу"

Формат JSON

```json
{
  "tasks": [
    {
      "id": 1,
      "date": "2025-04-15 14:30:00",
      "type": "работа",
      "task": "Написать отчёт"
    }
  ],
  "next_id": 2
}
```
