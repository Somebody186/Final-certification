# Training Planner

**Автор:** Somebody186

## Описание

Приложение для планирования тренировок с графическим интерфейсом (tkinter). Позволяет добавлять, удалять и фильтровать тренировки. Данные сохраняются в JSON-файл.

### Функциональность
- Добавление тренировок (дата, тип, длительность)
- Валидация ввода (формат даты, положительная длительность)
- Фильтрация по дате и типу тренировки
- Удаление записей
- Автосохранение в `trainings.json`
- Загрузка данных при запуске

## Требования
- Python 3.7+
- Стандартные библиотеки: tkinter, json, datetime, unittest

## Установка и запуск

```bash
git clone https://github.com/Somebody186/Final-certification.git
cd Final-certification
python main.py
```

Запуск тестов

```bash
python test_manager.py
```

Примеры использования

Добавление тренировки

1. Введите дату: 2025-04-20
2. Выберите тип: Бег
3. Введите длительность: 45
4. Нажмите "Добавить тренировку"

Фильтрация

· По дате: введите 2025-04-20 → нажмите "Применить фильтр"
· По типу: выберите Плавание → нажмите "Применить фильтр"
· Сброс: нажмите "Сбросить фильтр"

Удаление

· Выберите строку в таблице → нажмите "Удалить выбранную"

Тестирование

Проверены сценарии:

· Позитивные: добавление, фильтрация, удаление
· Негативные: пустые поля, неверный формат даты, отрицательная длительность
· Граничные: нулевая длительность (отклоняется), очень большое число, специальные символы

Структура JSON

```json
{
  "trainings": [
    {"id": 1, "date": "2025-04-20", "type": "Бег", "duration": 45}
  ],
  "next_id": 2
}
```
